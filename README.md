# HexaTower - Prototype

This codebase was my third try at creating Hexatower, a chess-inspired turn based video game. This codebase prototyped the gameplay, ensuring it is fun.

Feel free to poke around the codebase, but keep in mind that this was a prototype. The priority was speed of development, not maintainability. Some parts of this code are held together with duct tape and chicken wire. If interested, I recommend exploring the [sequel codebase](https://github.com/OliverWPierce/HexaTower--Multiplayer) where I take this game's concept and make it truly multiplayer under a listen-server architecture.
