# HexaTower - Prototype

This codebase was my third try at creating Hexatower, a chess-inspired turn based video game. This codebase prototyped the gameplay, ensuring it is fun.

Feel free to poke around the codebase, but keep in mind that I was significantly less experienced in Rust and Programming as a whole when I created it. Some parts of this code are essentially held together with duct tape and chicken wire. This is because I was inexperienced, and it is a prototype. For a more accurate display of my skill, checkout the sequel repository, Hexatower 2, where I made the concept multiplayer. Further, for a demo of gameplay, check out my website oliverpierce.com
